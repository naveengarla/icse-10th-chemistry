# Clear-writing rules for chapter content (STE-lite)

Paste this block at the end of a chapter request, or say "follow prompts/clear-writing.md".
It adapts ASD-STE100 (Simplified Technical English) to ICSE Class 10 Chemistry content.
Goal: a 15-year-old reads each line once and gets it right.

---

Write all concept text and lesson steps by these rules.

## 1. Sentences
- Keep sentences short. Aim for 15 words or fewer, never more than 20.
- Put one idea in one sentence.
- Do not use semicolons. Use two sentences.
- Use simple present tense for facts: "Ammonia turns red litmus blue."
- Use plain words: "use", not "utilise". "Start", not "commence".

## 2. Steps (lab procedures, numericals, equation balancing)
- Number every step.
- Put one action in one step.
- Start the step with the verb: "Heat the test tube gently."
- Say who or what acts. Not "effervescence is seen" but "The gas bubbles out of the solution."
- Put the observation in its own line: "You see: …"

## 2b. "Why?" table (the student likes this one)
- After each method or experiment, add a two-column table: **Question | Answer**.
- Each question starts with "Why …?" (or "Why not …?") and asks about one choice: a reactant, a condition, a drying agent, a collection method, a precaution.
- Answer in 1–3 short sentences. The first sentence gives the reason she can write in the exam.
- Include the "Why not …?" rows. They cover the wrong choices the exam asks about (e.g. "Why not nitric acid?").

## 3. One name per thing
- At the top of each lesson, write a short **Terms** list. Each term gets one name.
- If the textbook uses other names, list them once there: "Iron(II) sulphate (also: ferrous sulphate)".
- After that, use only the chosen name in explanations. Do not rotate synonyms.

## 4. Do NOT simplify these (exam language)
- ★ Definitions that must be learnt by heart. Copy the textbook wording exactly.
- Model exam answers. Keep the ICSE style, including passive voice ("The mixture is heated", "A white precipitate is formed").
- Chemical names, formulae, equations and units. Never shorten them.
- Mark these lines clearly so the student knows: "Learn this exactly."

## 5. Never lose content
- Keep every fact, condition and exception from the source ("only when dilute", "except Pb").
- If a shorter sentence would drop a condition, keep the longer sentence.
- Simplify the words, not the chemistry.

## 6. Self-check before finishing
- Any sentence over 20 words? Split it.
- Any step with two actions ("and then")? Split it.
- Any thing called by two names in the explanations? Use the Terms-list name.
- Did any ★ definition or model answer get rewritten? Restore the textbook wording.
